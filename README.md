# T3 LoRa32 Firmware

Firmware for the lora T3 esp32 board. Supports transmit and recieve with uart reading and writing for a chat client. 

## Build and Flash

you can build with 

```bash
idf.py build
```

or if you want to flash and build just run

```bash
idf.py flash -p <your tty device here>
```
